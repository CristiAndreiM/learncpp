# Week 1 Recap: types, const/constexpr, static

C++ program, demonstrating:
- fixed-width types (`uint8_t`) and unsigned wrap around
- `constexpr` constants and functions
- a `static` local variable counting function calls

## Build
g++ -std=c++17 -Wall -Wextra main.cpp -o program
./program
